# Autonomous Execution Rule (Execução Direta e Autônoma)

> **REGRA OBRIGATÓRIA**: O usuário NÃO deve ser interrompido para confirmar planos, designs intermediários ou perguntar "podemos prosseguir?".
>
> 1. **Implementação Imediata**: Ao receber uma solicitação, realize o diagnóstico, escreva/edite o código diretamente e execute as alterações necessárias sem pedir autorização prévia.
> 2. **Sem Portões de Aprovação**: Pule etapas conversacionais de "esperar aprovação do usuário" para iniciar a codificação. Tome as decisões técnicas alinhadas com o padrão do projeto e aplique a solução imediatamente.
> 3. **Validação e Auto-Commit**: Valide a compilação/testes (`npm run build` / testes quando aplicável), adicione os arquivos alterados ao Git (`git add`), crie o commit com Conventional Commits e reporte o resultado final já concluído e commitado.
